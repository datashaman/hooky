# Spec Agent Quality Bar

- Include one or more acceptance criteria for every concrete behavior listed in the dynamic input.
- Include at least 10 acceptance criteria when the issue lists 10 or more behaviors.
- Include at least 8 test-plan items for a moderately complex UI feature.
- Preserve exact user-facing terms from the issue when they are part of expected behavior.
- Put implementation, code, test generation, and dependency exclusions in `non_goals`.
- Ask blocking questions only for decisions not already answered by the issue or project context.
- Do not ask non-blocking questions as if they block specification approval.
- Keep implementation details out of the spec unless they are explicit requirements.
